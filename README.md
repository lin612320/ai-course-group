## 目录规范

每个项目一个顶层目录，内部统一按下面分：

```
项目X-名称/
├── 01-研究报告/      # 报告正文（docx + 源 markdown）
├── 02-演示/          # 汇报用 pptx / pdf
├── 03-源代码/        # 完整可编译工程 + 运行说明
├── 04-文档/          # 过程文档：分工、审查、对标数据
├── 05-工具脚本/      # 生成报告和 PPT 的脚本
└── 06-资源/          # 背景图等素材
```

## 约定

- 源码统一 UTF-8 编码，缩进 4 空格。
- 提交信息用 `项目X: 做了什么` 的格式，例如 `项目一: 修正阶段三加权参数`。
- 编译产物（`out/`、`*.class`）、IDE 本地配置（`workspace.xml`）、临时快照 zip 不进仓库。
- 报告和 PPT 的源文件（markdown、生成脚本）与成品（docx、pptx）一起提交，保证可复现。
