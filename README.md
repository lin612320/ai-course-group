## 目录规范

每个项目一个顶层目录，内部统一按下面分：

```
项目X-名称/
├── 01-研究报告/      # 报告正文（docx + 源 markdown）
├── 02-演示/          # 汇报用 pptx / pdf
├── 03-源代码/        # 完整可运行工程 + 运行说明
├── 04-文档/          # 过程文档：分工、审查、对标数据
├── 05-工具脚本/      # 生成报告和 PPT 的脚本
├── 06-资源/          # 背景图等素材
└── 07-提交件/        # 报告 PDF、贡献表、提交包
```

## 约定

- 源码统一 UTF-8 编码，缩进 4 空格（Python 同）。
- 提交信息用 `项目X: 做了什么` 的格式，例如 `项目二: 补 Task 3 像素/HOG 对照`。
- 编译产物（`out/`、`*.class`）、Python 缓存（`__pycache__/`）、虚拟环境（`.venv/`）、IDE 本地配置不进仓库。
- 数据集与实验产物（`datasets/`、`results/`、`models/`、`*.joblib`）不进仓库：数据用官方来源，运行说明写清获取方式，结果由命令重新跑出来。
- 报告和 PPT 的源文件（markdown、生成脚本）与成品（docx、pptx）一起提交，保证可复现。
- 每个项目的公共模块只有一人有写权限，其余人提《改动申请》，具体见各项目 `04-文档/` 下的分工方案。
