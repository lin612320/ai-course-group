# 运行说明

## 环境

Python 3.10 或更新版本，纯 CPU 即可，无需 TensorFlow 或 GPU。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r svm_project/requirements.txt
```

下文的 `python` 指装好依赖的解释器；未激活环境时替换为 `.venv/Scripts/python.exe`。命令在 `03-源代码/svm_project/` 目录下执行。

## 数据

- **手写数字**：`sklearn.datasets.load_digits()` 自带，无需下载。仓库内 `06-资源/数据/digits.gz` 是同一份数据的留痕（1797 行，前 64 列像素 0–16、末列标签）。
- **Fashion-MNIST**：仓库已内置官方四个 IDX.gz，位置 `06-资源/数据/fashion/`，直接指过去即可，不用联网。

```powershell
# 推荐：用仓库自带数据（三阶段必须传同一路径）
python main.py --task 3 --stage validate --data-dir "../../06-资源/数据/fashion"
```

也可以用程序下载，或指向别处的数据：

```powershell
# 联网下载到默认目录 datasets/fashion
python main.py --task 3 --stage validate --download

# 数据在别处
python main.py --task 3 --stage validate --data-dir "D:/datasets/fashion"
```

也支持 `--npz` 传入含 `x_train`/`y_train`/`x_test`/`y_test` 的 NPZ，图像须为未归一化 `uint8`、保持官方 60000/10000 划分。

## 三个 Task

```powershell
# Task 1：基线（只跑 validate，最终测试在 Task 2 做）
python main.py --task 1 --stage validate

# Task 2：三组对照 + 参数搜索 → 重训 → 测试
python main.py --task 2 --stage validate
python main.py --task 2 --stage refit
python main.py --task 2 --stage test

# Task 3：服装分类（数据用仓库自带）
D = "../../06-资源/数据/fashion"
python main.py --task 3 --stage validate --data-dir $D
python main.py --task 3 --stage refit    --data-dir $D
python main.py --task 3 --stage test     --data-dir $D

# Task 3 扩展实验（PCA + RBF）：只有 validate 带 --extended，后两步不加
python main.py --task 3 --stage validate --extended --output results/task3_extended --data-dir $D
python main.py --task 3 --stage refit  --output results/task3_extended --data-dir $D
python main.py --task 3 --stage test   --output results/task3_extended --data-dir $D
```

## 流程自检

```powershell
python -m unittest discover -s checks -v
```

5 项检查：重训只用训练＋验证数据、test 不调用 `fit`、重训后改配置会被拒绝、数据变化会被拒绝、Task 1 不允许测试。公共模块有任何改动后必跑，且 Task 1 验证准确率要与改动前逐位一致。

## 三条硬约束

1. `validate`、`refit`、`test` 三次必须用同一 `--output` 与同一数据选项，否则 `refit_manifest.json` 的指纹校验直接拒绝。
2. 标准化与 PCA 只在训练数据上拟合；测试集只评一次，出结果后不回头改方案。
3. 不同实验用不同的 `--output` 目录区分，不改 `config.py` 的默认值来区分。

## 输出

默认写入 `results/task编号/`：

| 文件 | 含义 |
|---|---|
| `data_counts.csv`、`samples.png` | 数据分布与图像样例 |
| `ablation_validation.csv` / `feature_comparison.csv` | 固定条件对照 |
| `search_validation.csv` | 参数搜索与验证分数 |
| `selected_config.json` | 验证集选定的参数、特征设置与数据指纹 |
| `refit_summary.csv`、`refit_manifest.json` | 重训过程与模型记录 |
| `test_results.csv` | Accuracy、Macro-F1、维数、重训耗时 |
| `<模型>_test/` | 分类报告、混淆矩阵、预测明细、错例 |
| `confusion_pairs.csv` | Task 3 两组混淆类别与两个方向错分比例 |
| `environment_<阶段>.json`、`run_config_<阶段>.json` | 设备、依赖与运行配置 |

`results/`、`models/`、虚拟环境与 `__pycache__` 不进仓库；数据只在 `06-资源/数据/` 放一份。
