# 运行说明

## 环境

- JDK 17 及以上（开发时用的是 JDK 19）
- IntelliJ IDEA
- 不依赖任何第三方库

## 导入工程

1. IDEA 打开 `WattAi` 目录。
2. 如果 `src` 是灰色：右键 `src` → Mark Directory as → Sources Root，变蓝就对了。
3. 编码统一 UTF-8：File → Settings → Editor → File Encodings，三处都改成 UTF-8。
4. 编译输出到 `out/production/WattAi`。

## 主入口

`core.runner.SearchTester`，需要四个参数：

```
resources/problems.txt NPUZZLE 1 stud.g01.runner.PuzzleFeeder
```

依次是：数据文件、问题类型、阶段号、Feeder 类。

## 四个阶段的数据文件

| 阶段 | 文件 |
|---|---|
| 一 | `resources/problems_stage1.txt` |
| 二 | `resources/problems_stage2.txt` |
| 三 | `resources/problems_stage3.txt` |
| 老师给的原始验收 | `resources/problems.txt` |

另有两个按算法整理的文件：`problems_astar.txt`、`problems_idastar.txt`。

## 常用 VM 参数

| 参数 | 作用 |
|---|---|
| `-Xmx4g` | 阶段三用 IDA\* 时要加，默认堆不够 |
| `-Dnpuzzle.pdb=555` | 模式数据库分组方式，默认就是 5-5-5 |
| `-Dnpuzzle.pdb=663` | 换成 6-6-3，对照实验用，更慢 |
| `-Dnpuzzle.pdb=multi` | 多套划分取最大值，对照实验用 |
| `-Dnpuzzle.weight=1.2` | 加权 IDA\*，阶段三的达标方案 |
| `-Dnpuzzle.gui=true` | 求解完成后弹出可视化窗口 |

## 可视化

两个入口都行。

**入口一**：直接运行 `stud.g01.gui.PuzzleVisualizer`，前四个参数和 SearchTester 一致，后面可以任意顺序加启发函数名、实例范围、`--ida`：

```
resources/problems_stage2.txt NPUZZLE 2 stud.g01.runner.PuzzleFeeder DISJOINT_PATTERN 1-6
```

实例范围支持 `3`（单个）、`2-6`（区间）、`all`（全部）。批量演示时关掉当前窗口会自动弹下一个，全部放完控制台打一张汇总表。

**入口二**：给 SearchTester 加 `-Dnpuzzle.gui=true`，解完自动弹窗。

键盘：空格播放/暂停，← / → 单步前后，Home / End 跳到开头/结尾。

## 批量实验

`stud.g01.runner.ExperimentRunner` 用来复现报告第 4 章的表格数据，参数是数据文件和 Feeder 类，后面接实验选项。

## 已知问题

- Word 打开某些 docx 时如果提示更新域，点“是”即可，目录和页码会自动重算。
- 阶段三的倒序实例用 A\* 一定 OOM，这是 A\* 本身的内存特性，换 IDA\* 即可。
